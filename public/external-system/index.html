📅 12月シフト生成システム

📌 システムファイルを配置してください

外部で作成したシフト生成システムのファイルを以下のディレクトリに配置してください:

/public/external-system/

💾 データ永続化API

生成したシフトデータは以下のAPIを使用して保存できます:

📤 データを保存

POST /api/external-shifts/december { "year": 2025, "month": 12, "shifts": [...] }

📥 データを取得

GET /api/external-shifts/december

✨ 機能

  • データは自動的にバックアップされます
  • サーバー再起動後もデータは保持されます
  • バックアップは /data/december-shifts/backups/ に保存されます

📖 詳細は /public/external-system/README.md を参照してください
