# アーカイブされたシフト生成器

このフォルダには、古いシフト生成ロジックがアーカイブされています。
これらは新しい`improvedShiftGenerator.ts`に置き換えられました。

## アーカイブされたファイル

### 1. shiftGenerator.ts
- **目的**: 初期の単純なシフト生成器
- **問題点**: 希望休の保護機能がなく、リセット時にすべてのデータが削除される

### 2. aiShiftGenerator.ts
- **目的**: AIを使用したシフト生成
- **問題点**: 希望休の固定化が不完全で、AIの判断により上書きされる可能性がある

### 3. phaseBasedShiftGenerator.ts
- **目的**: 3段階のフェーズで生成する改良版
- **問題点**: 固定データと生成データの区別がなく、リセット時に希望休も削除される

## 新しい実装（improvedShiftGenerator.ts）の改善点

1. **固定データの保護**: 承認済み希望休・勤務希望を`isFixed=true`として保護
2. **リセット時の保持**: 固定データはリセット時も削除されない
3. **ソース追跡**: `sourceType`と`sourceId`で元データを追跡可能
4. **段階的生成**: 固定データを優先し、その後で追加生成
