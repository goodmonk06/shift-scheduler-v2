# 勤務表PDF生成ツール - 統合ガイド

## 📋 概要
このツールは、シフト生成ソフトのデータを受け取り、A4横向きで印刷可能な勤務表（シフト表）PDFを生成します。

---

## 🎯 バックエンドエンジニア向け指示

### 1. データ形式（JSON）
以下の形式でデータを提供してください：

```typescript
interface ShiftData {
  facilityName: string;              // 施設名（例：「グループホーム○○」）
  month: number;                     // 月（1-12）
  year: number;                      // 年（例：2025）
  events?: Record<number, string>;   // 日付ごとの行事予定（オプション）
  errorDays?: number[];              // 人数不足エラーがある日付の配列（オプション）
  staff: Array<{
    name: string;                    // スタッフ名
    position: string;                // 勤務区分（※現在非表示だが、データ構造には含める）
    shifts: Record<number, string>;  // { 1: "9～17", 2: "休", 3: "夜", ... }
  }>;
}
```

### 3. フィールド詳細説明

#### **facilityName** (必須)
- 施設名を文字列で指定
- 例：`"グループホーム○○"`, `"特別養護老人ホーム△△"`

#### **month / year** (必須)
- `month`: 1～12の数値
- `year`: 4桁の年（例：2025）
- この値から自動的に月の日数（28～31日）を計算します

#### **events** (オプション)
- 日付ごとの行事予定を設定
- キー：日付（1～31の数値）
- 値：行事名（文字列、空文字列可）
- **省略可能**：データがない場合は`null`または省略してOK
- 例：`{ "3": "避難訓練", "15": "誕生会", "25": "" }`

#### **errorDays** (オプション)
- **重要**：人数不足のバリデーションエラーがある日付を配列で指定
- 指定された日付の行事予定行が**黄色背景**で表示されます
- **省略可能**：エラーがない場合は`null`または省略してOK
- 例：`[3, 15, 22]` → 3日、15日、22日が黄色でハイライト

#### **staff** (必須)
- スタッフの配列
- 各スタッフには以下の情報が必要：
  - `name`: スタッフ名（文字列）
  - `position`: 勤務区分（文字列、現在非表示だがデータには含める）
  - `shifts`: 日付ごとのシフト情報（Record<number, string>）

#### **shifts** (必須)
- キー：日付（1～31の数値）
- 値：シフト内容（文字列）
- **空のシフト**：空文字列`""`または省略可能
- 例：`{ "1": "9～17", "2": "休", "3": "夜", "4": "明", "5": "" }`

### 4. シフト内容と色の自動判定ルール

システムは以下のキーワードで自動的に色分けします：

| キーワード | 背景色 | 説明 |
|-----------|--------|------|
| **「夜」「明」を含む** | 青色 (#0ea3db) | 夜勤、夜勤明け |
| **「早」を含む** | 緑色 (#739058) | 早番 |
| **「休」「有」を含む** | 赤ピンク (#e38c82) | 休み、有給休暇 |
| **土曜日** | 薄い青 (#cfe2f3) | 土曜日の背景 |
| **日曜日** | 薄い赤 (#f4cccc) | 日曜日の背景 |
| **その他** | 白 | 通常勤務 |

#### 例：
- `"夜"` → 青色
- `"夜勤"` → 青色
- `"明け"` → 青色（「明」を含む）
- `"早番"` → 緑色
- `"8時半早番"` → 緑色（「早」を含む）
- `"休"` → 赤ピンク
- `"有休"` → 赤ピンク
- `"9～17"` → 白（土日の場合は土日の色）
- `"8半～12半"` → 白

### 5. バリデーション要件

#### 必須チェック項目：
1. **日付の整合性**：`shifts`のキーが1～その月の日数の範囲内か
2. **スタッフ配列**：最低1人以上のスタッフが必要
3. **月と年**：有効な値か（month: 1-12, year: 妥当な年）

#### 人数不足エラーの検出：
- 各日の勤務人数が基準を下回る場合、その日付を`errorDays`配列に追加
- 例：3日、15日、22日が人数不足 → `errorDays: [3, 15, 22]`

### 3. PDF出力方法

#### ユーザー操作：
1. 画面右上の「PDF出力」ボタンをクリック
2. ブラウザの印刷ダイアログが開く
3. **「送信先」で「PDFとして保存」を選択**
4. **用紙サイズ：A4**
5. **レイアウト：横向き**
6. **余白：なし**
7. 「保存」をクリック

#### プログラム的に実装する場合：
```tsx
const handlePrint = () => {
  window.print();
};
```

### 4. レスポンシブ対応

- **自動縮小機能**：スタッフが増えた場合、縦方向のみ自動縮小してA4に収まるように調整
- **フォントサイズ調整**：
  - 5人以下：11px
  - 6～8人：10px
  - 9～12人：9px
  - 13人以上：8px
- **月の日数対応**：28～31日に自動対応（列数が自動調整）

### 5. 色のカスタマイズ

ユーザーは画面右側の「色設定」パネルから以下を変更可能：
- 夜勤の色
- 早番の色
- 休暇の色
- 土曜日の色
- 日曜日の色

設定は`localStorage`に保存され、次回アクセス時も維持されます。

## 🔧 トラブルシューティング

### Q1: 印刷時に表が崩れる
**A**: ブラウザの印刷設定を確認してください
- 余白：なし
- 用紙：A4横向き
- 背景のグラフィック：オン

### Q2: データが表示されない
**A**: データ形式を確認してください
- `shifts`のキーは**数値型**（例：`1`, `2`, `3`）
- 文字列型（例：`"1"`, `"2"`）の場合は変換が必要

### Q3: 黄色背景が表示されない
**A**: `errorDays`の形式を確認してください
- 数値の配列（例：`[3, 15, 22]`）
- 文字列配列（例：`["3", "15"]`）の場合は数値に変換

### Q4: 人数が多すぎて見切れる
**A**: 自動縮小機能が動作しているか確認してください
- CSS: `--base-font-size` が正しく計算されているか
- 最大20人程度まで対応（それ以上は手動調整が必要）
