## システム概要

本システムは、介護施設向けの高度なシフト管理システムです。AI自動生成機能、希望休・変更提案のワークフロー管理、5年間のアーカイブ機能を備えています。

### 主な機能

**管理者機能**
- 職員管理（追加・編集・削除・プロフィール表示）
- 役職グループ管理
- 勤務時間枠管理
- 職場ルール設定（正社員・パート別）
- 必要人数設定（24時間×7曜日のマトリクス）
- シフト作成・編集（カレンダーUI）
- AI自動生成（2段階生成：パート→正社員）
- 希望休管理（承認・却下）
- 変更提案管理（承認・却下）
- 緊急通知作成
- 統計・レポート表示
- アーカイブ管理（過去5年分）

**職員機能**
- シフト確認（月別カレンダー）
- 希望休申請（期間選択・理由入力）
- 変更提案（日付・時間帯・理由入力）
- 緊急通知確認

## 管理者向け操作ガイド

### ログイン方法

プレビューURLにアクセスすると、自動的にManus OAuthのログイン画面にリダイレクトされます。管理者用のメールアドレス（kinyu000@gmail.com）でログインしてください。

### ダッシュボード

ログイン後、ダッシュボードが表示されます。以下の情報が確認できます。

- **登録職員数**: 現在登録されている職員の総数
- **今月のシフト**: 現在作成されているシフトの年月
- **緊急通知**: 未読の緊急通知件数
- **アーカイブ**: 保存されているアーカイブの件数

### 職員管理

左サイドバーの「職員管理」をクリックすると、職員一覧が表示されます。

**職員の追加**
1. 右上の「職員を追加」ボタンをクリック
2. 名前、役職グループ、スキルレベル（50-100）、夜勤可否を入力
3. 「追加」ボタンをクリック

**職員の編集**
1. 職員一覧の右側にある鉛筆アイコンをクリック
2. 情報を修正
3. 「更新」ボタンをクリック

**職員の詳細表示**
1. 職員一覧の右側にある目のアイコンをクリック
2. プロフィールページが表示され、基本情報・個人制約・希望休が確認できます
3. 「職員一覧に戻る」ボタンで一覧に戻ります

**職員の削除**
1. 職員一覧の右側にあるゴミ箱アイコンをクリック
2. 確認ダイアログで「削除」を選択

### シフト作成

**新しいシフトの作成**
1. ダッシュボードの「新しいシフトを作成」をクリック
2. 年と月を選択
3. シフト名を入力
4. 「作成」ボタンをクリック

**シフトの編集**
1. 「シフト作成」メニューからシフト一覧を表示
2. 編集したいシフトの「編集」ボタンをクリック
3. カレンダーUIでシフトを編集

**AI自動生成**
1. シフト編集画面で「AI自動生成」ボタンをクリック
2. システムが以下の順序でシフトを生成します:
   - 第1段階: パートの配置（柔軟な勤務条件を優先）
   - 第2段階: 正社員の配置（不足分を補充・全体調整）
3. 生成されたシフトを確認し、必要に応じて手動で調整

### 希望休管理

**希望休の承認・却下**
1. 左サイドバーの「希望休管理」をクリック
2. 承認待ちの希望休が一覧表示されます
3. 各希望休の右側にある「承認」または「却下」ボタンをクリック
4. 処理済みの希望休は下部に表示されます

### 緊急通知の作成

**緊急通知の送信**
1. 左サイドバーの「緊急通知」をクリック
2. 右上の「通知を作成」ボタンをクリック
3. タイトル、メッセージ、緊急フラグを入力
4. 「送信」ボタンをクリック

**緊急通知の削除**
1. 通知一覧の右側にあるゴミ箱アイコンをクリック
2. 確認ダイアログで「削除」を選択

## 職員向け操作ガイド

### 職員画面へのアクセス

プレビューURLの後ろに `/employee` を追加してアクセスします。

```
https://3000-ii7ibkoe92o1hjhpq5ura-1cd7b2ad.manus-asia.computer/employee
```

### ホーム画面

職員画面のホーム画面には、以下のナビゲーションカードが表示されます。

- **シフト確認**: 自分のシフトを月別カレンダーで確認
- **希望休申請**: 希望休を申請
- **変更提案**: シフトの変更を提案
- **緊急通知**: 管理者からの緊急通知を確認

### シフト確認

**月別シフトの表示**
1. ホーム画面で「シフト確認」をクリック
2. 月を選択（前月・次月ボタンで移動可能）
3. カレンダー形式で自分のシフトが表示されます
4. 各日付には勤務時間帯が表示されます

### 希望休申請

**希望休の申請方法**
1. ホーム画面で「希望休申請」をクリック
2. 「新しい希望休を申請」ボタンをクリック
3. 開始日と終了日を選択（同じ日を選択すると1日のみの申請）
4. 理由を入力（任意）
5. 「申請」ボタンをクリック

**申請状況の確認**
- 申請一覧に自分の希望休が表示されます
- ステータスバッジで承認状況を確認できます:
  - **承認待ち**: 黄色のバッジ
  - **承認済み**: 緑色のバッジ
  - **却下**: 赤色のバッジ

### 変更提案

**シフト変更の提案方法**
1. ホーム画面で「変更提案」をクリック
2. 「新しい変更を提案」ボタンをクリック
3. 変更したい日付を選択
4. 希望する時間帯を選択
5. 理由を入力
6. 「提案」ボタンをクリック

## 希望休申請フロー

### 全体の流れ

希望休申請は以下の流れで処理されます。

```
職員が希望休を申請
    ↓
管理者が希望休管理画面で確認
    ↓
管理者が承認または却下
    ↓
職員が申請状況を確認
```

### 職員側の操作

**ステップ1: 希望休申請画面にアクセス**
- 職員画面（/employee）にアクセス
- 「希望休申請」カードをクリック

**ステップ2: 希望休を申請**
- 「新しい希望休を申請」ボタンをクリック
- 開始日: 2025-11-18
- 終了日: 2025-11-18
- 理由: 「私用のため」
- 「申請」ボタンをクリック

**ステップ3: 申請状況を確認**
- 申請一覧に新しい希望休が表示されます
- ステータスは「承認待ち」（黄色のバッジ）

### 管理者側の操作

**ステップ1: 希望休管理画面にアクセス**
- 管理者画面にログイン
- 左サイドバーの「希望休管理」をクリック

**ステップ2: 希望休を確認**
- 承認待ちの希望休が一覧表示されます
- 職員名、期間、理由を確認

**ステップ3: 承認または却下**
- 承認する場合: 「承認」ボタンをクリック
- 却下する場合: 「却下」ボタンをクリック

**ステップ4: 処理結果を確認**
- 処理済みの希望休は下部に移動します
- ステータスが「承認済み」または「却下」に変更されます

### 職員側で結果を確認

**ステップ1: 希望休申請画面に戻る**
- 職員画面（/employee）にアクセス
- 「希望休申請」カードをクリック

**ステップ2: 承認状況を確認**
- 申請一覧でステータスバッジを確認
- 承認済み: 緑色のバッジ
- 却下: 赤色のバッジ

## よくある質問

### Q1: 職員専用のログインはできますか？

**A**: 現在のManus OAuth認証では、職員専用ログインは未対応です。職員画面は `/employee` パスで直接アクセスできます。将来的には、職員ごとの個別ログイン機能を追加する予定です。

### Q2: スマートフォンで利用できますか？

**A**: はい、職員画面はスマートフォンに最適化されています。プレビューURLの後ろに `/employee` を追加してアクセスしてください。

### Q3: AI自動生成はどのように動作しますか？

**A**: AI自動生成は以下の順序で動作します:
1. **第1段階**: パートの配置（柔軟な勤務条件を優先）
2. **第2段階**: 正社員の配置（不足分を補充・全体調整）

この順序により、パートの勤務条件を優先しながら、正社員で全体を調整します。

### Q4: 希望休が却下された場合、どうすればいいですか？

**A**: 却下された希望休は、申請一覧で赤色のバッジで表示されます。管理者に直接相談して、理由を確認してください。必要に応じて、別の日程で再度申請できます。

### Q5: シフトをアーカイブするとどうなりますか？

**A**: アーカイブされたシフトは、通常のシフト一覧には表示されなくなります。アーカイブ画面から過去5年分のシフトを検索・閲覧できます。

### Q6: 緊急通知は誰に送信されますか？

**A**: 緊急通知は、全職員に一斉送信されます。職員画面のホーム画面に表示されます。
